# Một project vừa làm cha vừa ghi vault

Không cần mở chat Personal OS riêng — nếu làm đủ 3 bước dưới.

## Trong project TRƯỞNG THÀNH CÙNG GG (bố làm trên grok.com)

1. Connectors — bật **GitHub**. Account phải là `Warren-Githut` (đã admin repo).
2. Skills — gắn **cả hai**: `gg-bo` và `personal-os-automation`.
3. Instructions — thay đoạn cũ “không tự commit” bằng:

> Mặc định: làm cha (thăm, câu hai nhà, gen).
> Chỉ ghi GitHub khi tôi nói: ghi vault / commit / sửa file / nhét milestone.
> Repo duy nhất: Warren-Githut/personal-os-automation, nhánh master.
> Chỉ đụng file GG (10_PULSE/001-003, wiki/01_GG, _growth/COMMUNICATION_SKILL_WITH_GG, .scripts/skills/gg-parenting, .scripts/skills/gg-bo).
> Đọc hết file trên GitHub trước khi sửa. Không commit secret.

## Câu nói trong chat đó

- “Thăm con hôm nay” → playbook. Không commit.
- “Ghi vault milestone ngày …” → mới được push.
- “Sửa file 001 câu hai nhà” → mới được push.

Không nói “ghi hộ” khi chỉ đang hỏi cách nói với con.

## Nếu GitHub chưa hiện trong project GG

- Vào project → Connectors → GitHub → Connect / Reconnect.
- Thử câu: “đọc file 003 trên GitHub giúp bố”.
- Hiện được nội dung file = đã nối. Chưa hiện = chưa commit được, đừng giả.
