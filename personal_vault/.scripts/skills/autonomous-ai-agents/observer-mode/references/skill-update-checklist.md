# Skill Update Checklist

## Source
Derived from user's skill library management protocol. Used at each session end.

## Post-Session Review Steps

1. Scan conversation for **learning signals** (any one warrants action):
   - User corrected style, tone, format, verbosity, or legibility
   - Frustration patterns: "stop doing X", "too verbose", "don't format like X", "just give me the answer"
   - User corrected workflow or sequence of steps
   - Non-trivial technique, fix, workaround, or tool-usage pattern emerged
   - Loaded skill was wrong, missing a step, or outdated
   - Explicit "remember this" directive

2. Select action per priority:
   - **Patch currently-loaded skill** — if it covers the territory
   - **Patch existing umbrella skill** — broadens trigger or adds pitfall
   - **Add reference file** under existing umbrella — session-specific detail or knowledge bank
   - **Create new umbrella** — only if no existing skill fits; name must be class-level

3. Do NOT capture:
   - Environment-dependent failures (missing binaries, unconfigured credentials)
   - Negative claims about tools that may be resolved later
   - Session-specific transient errors that resolved
   - One-off task narratives

4. When in doubt: prefer adding to an existing umbrella over creating new.

5. Session report: output `Recorded / Signals / Actions` block.
