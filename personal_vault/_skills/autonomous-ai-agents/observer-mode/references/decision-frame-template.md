# Decision Frame Templates

## Source
Domain 1 Session 1.1 — Communication Style training data from user.

## Standard Decision Frame

```
RECOMMENDATION: [one sentence, no hedging]

TRADEOFFS:
| Option | Upside | Downside |
|--------|--------|----------|
| A      | ...    | ...      |
| B      | ...    | ...      |

NEXT STEP: [concrete action, not "consider exploring"]
```

## Tool/Integration Decision Frame

```
ASSESSMENT: [needed vs premature]

IF premature:
- Current tool adoption rate: [X%]
- Hidden cost: [migration debt, re-wiring hours]
- Recommendation: [wait / pilot <X> first]

IF needed:
- IMPLEMENT:
  1. [First concrete step]
  2. [Second concrete step]
  3. [Validation check]
```

## Metric Optimization Frame

```
VISIBLE METRIC: [COL% / COGS% / etc.] → [current → target]

HIDDEN COSTS TO SURFACE:
- [Cost 1: staff morale decay = ?]
- [Cost 2: migration debt = ?]
- [Cost 3: training overhead = ?]

NET EFFECT: [calculate before presenting]
```
